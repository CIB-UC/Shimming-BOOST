Ring placement — where each printed ring goes

Each Ring_N folder of inserts mounts at the axial slot below. “Trays filled” reads the shim CSV on disk, so a sparse layout (insert search / OSII import) shows exactly which trays carry magnets. Refreshes after each run.

4

Python verifier

Which field

Measured field the shimmed result is compared against. Blank = the same scan as Stage 0.

Uses the same scan, magnet Br/side and coordinate unit as the rest of the pipeline — none of those are entered twice.

Which shim layout

Default = this iteration’s shim CSV (optimizer export, insert search or OSII import). Its ring numbers are converted to axial z, and rotated back into the scanner’s frame if B0 isn’t already along +y.

What to run

Independent magpylib model (no shared code with the Julia kernels), so agreement with the optimizer’s ppm is a real cross-check. Needs Python packages from Shimming_verifier/requirements.txt. Also runs at the end of a full run when run_python_verifier is on.
